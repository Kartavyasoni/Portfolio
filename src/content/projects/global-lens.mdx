## Overview

Global Lens turns a sprawling, slow-to-query set of development indicators into
something you can actually reason about — economic profiles that group similar
countries, forecasts that project where they're heading, and a dashboard for
asking "what if?".

## Ingestion that stays fast

A **Python and FastAPI** pipeline ingests **1,000+ global indicators**. The
bottleneck wasn't modeling — it was waiting on upstream APIs, so I added a
response caching layer that **cut median API latency by 60%**, which is what made
interactive exploration feel instant instead of sluggish.

## Profiles and forecasts

- **PCA + K-Means** reduced dozens of correlated indicators into a handful of
  components and grouped countries into **five economic profiles**, enabling
  comparisons across regions, income levels, and long-term development patterns.
- **ARIMA** models with **rolling-window validation** reduced GDP forecast
  **MAPE by 12%** against a historical-average baseline across evaluated periods.

## Delivery

The whole thing ships as a **Dockerized Streamlit dashboard** with scenario
controls, so a user can compare countries, indicators, forecasts, and cluster
profiles through one interactive interface — no notebook required.
