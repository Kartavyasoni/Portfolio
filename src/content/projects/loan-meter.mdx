## Overview

Loan Meter is a credit-risk model built for the real constraints of lending:
heavily imbalanced data, a hard precision requirement on approvals, and a
regulatory need to **explain every individual decision** — not just produce a
score.

## Reproducible preprocessing first

Before any modeling, **200,000+ loan records** run through Pandas pipelines
handling missing-value treatment, outlier controls, and feature validation. The
preprocessing is reproducible by design, so results can be regenerated and
defended later.

## Handling imbalance honestly

With a ~**10:1 class imbalance**, raw accuracy is meaningless. **Cost-sensitive
learning** made the model attend to the rare default class, **lifting
minority-class recall by 14%** over a standard-threshold baseline — while
preserving approval precision, which is the metric the business actually cares
about.

## Tuned for the right metric

The XGBoost classifier was optimized through **Bayesian search**, reaching
**0.76 ROC-AUC** on held-out data with better separation of higher-risk
applicants.

## Explainability as a requirement

Every prediction carries **SHAP-based reason codes**, helping reviewers
understand the drivers behind a default prediction and supporting transparent
model documentation for compliance and audit discussions. Explainability was a
design constraint, not an afterthought.
