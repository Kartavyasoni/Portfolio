## Overview

FilingQA is a retrieval-augmented research assistant for SEC 10-K filings. Ask it
a question about a company's financials and it answers in plain language — but
only using text it can cite from the actual filing. The goal was a system an
analyst could *trust*, not just a chatbot that sounds confident.

## Retrieval before generation

The hard part of RAG isn't the model — it's the retrieval. FilingQA ingests
10-K filings from **SEC EDGAR**, segments each document **by section**, and
embeds the chunks with **Sentence Transformers** into **pgvector**. Semantic
search then surfaces the passages most relevant to a question, which FastAPI
serves as ranked results for both the assistant and downstream applications.

## Grounded, citation-first answers

Answers are generated with the **Claude API** under controlled prompts that
require every response to reference retrieved filing passages. By forcing the
model to cite, unsupported interpretations drop sharply — the system says "here's
what the filing states," not "here's what I think."

## Measured, not vibes

Before releasing it for portfolio demonstration, I built a **100-question
evaluation set** measuring **hit-rate@5**, retrieval relevance, citation
coverage, and answer faithfulness — so quality is a number I can point to, not a
gut feeling.
